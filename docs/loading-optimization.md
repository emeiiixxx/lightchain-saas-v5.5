# 分享页加载优化

2026-11-03，本轮只修改本地，未发布。

## 原因与处理

- 原构建将各页面和编辑器打入同一个859.11 kB脚本。隐藏的试衣页仍挂载自动播放视频。改为首次进入页面才加载，访问后保留挂载以保存草稿；离开试衣页移除示例视频源。抠图和示意编辑器按需加载。
- React、React Flow等依赖独立为稳定的vendor文件，普通业务更新可复用浏览器缓存。视频页首次访问仍需要主入口、vendor和视频页三个文件，不能把主入口缩小等同于全部下载量下降。
- 32px头像原先请求1,816,973字节PNG，改为96px WebP，4,746字节；20px工作区图标由1,272,437降至1,570字节。
- 素材库、参考图使用240/960长边WebP显示版本。原文件仍用于大图预览、导出、像素裁切及明确宽度大于320px的画布素材，避免影响画布放大。用户上传和外链图片保持原有流程。
- 删除12份字节完全相同的图片，并统一引用；映射见asset-deduplication.json。删除6份无运行引用的旧示例，清单见retired-demo-assets.json，历史原件可从Git恢复。
- 保留现有演示原素材、视频和本地未发布的花园/走秀内容。Slider、GradientText、PromptAssistButton按项目约定继续作为可复用组件保留，未被引用时不进入运行包。

## 体积与验证

本地public由169.18 MiB变为142.75 MiB，净减少约26.43 MiB；其中新增显示版本约3.09 MiB。public总量不是首屏下载量。

通过TypeScript及GitHub Pages路径构建、339处发布资源路径检查、45处模版/素材库/试衣数据路径检查；验证小图srcset、大图保留原始src、外链和blob不被改写。未做浏览器视觉验收。

当前线路单次线上HTML请求约0.76秒，主脚本约1.08秒（压缩传输约276 kB）。这是单次网络测量，不能代表用户线路或完整首屏时间。GitHub Pages跨网络访问差异仍可能影响加载。

## 维护

新增已跟踪的演示图片后，使用安装Pillow的Python运行：

```
python scripts/generate-display-images.py
python scripts/generate-image-previews.py
node scripts/build-pages.mjs
```

显示版本由内容哈希命名，相同原图只生成一组；脚本只清理自己生成的display目录，不删除原始素材。原始素材路径不可因缩略图优化而替换为低分辨率文件。
