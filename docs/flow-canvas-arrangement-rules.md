# Flow 画布整理规则

1. **范围**：每次整理整个画布，选区不影响整理范围。
2. **归组**：按当前连接关系归组。同一任务的输入图、编辑器和结果一起排列，不按上传批次拆分。
3. **组内**：输入图按节点内的列表顺序排列；从左到右为输入图 → 编辑器 → 结果，后续步骤继续向右。
4. **组间**：无依赖的任务按创建顺序排列；有依赖的任务先上游、后下游。追加旧素材不改变任务先后。
5. **共用素材**：已有工作流保留原组，通过连线供其他任务引用；共用图片只保留一份。独立图片优先归属仍有效的原任务，否则归属当前引用它且创建最早的任务。
6. **未关联内容**：未连接的图片和空节点放在下方独立区域，按加入画布的顺序排列。
7. **整理结果**：自动适应屏幕，支持撤销；不改变图片尺寸、内容及连接关系。内容和窗口尺寸不变时，重复整理位置不变。

例：先上传 4 张，之后再上传 4 张，全部接入同一编辑器 → 8 张输入图归为一组，与编辑器及结果一起排列。
